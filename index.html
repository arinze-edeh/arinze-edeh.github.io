Troubleshooting

Live faults, traced to the root cause and fixed

Kubernetes volume mounts

Containers would not start. Pod describe output and logs pointed to wrong mount paths and mismatched claims. Fixed the manifest and confirmed readiness.

Dockerfile build failures

Inspected build output layer by layer, corrected base image incompatibilities, and verified with full build and run cycles.

MariaDB outage

Used service status and error logs to isolate a configuration fault, corrected it, and tested connectivity after recovery.

Linux process and network faults

Found runaway and failed processes, and traced service binding problems through socket inspection and configuration review.

EC2 not reachable from the internet

Checked the route table, internet gateway, security group rules, and public IP in turn to find the blocking setting.

Azure VM without internet access

Traced the fault through the VNet, subnet routes, network security group rules, and public IP association.
